## 📖 About

**Gemini AI Projects** is a growing collection of modern, production-ready AI applications, each built as a standalone module powered by the **Google Gemini API**.

Every project shares the same core stack — **Next.js, TypeScript, and Tailwind CSS** — so you can explore, learn from, or extend any of them with a consistent developer experience.

## 🛠️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/gemini-ai-projects.git
cd gemini-ai-projects
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Then open **[http://localhost:3000](http://localhost:3000)** in your browser.

---

## 🔑 Environment Variables

Create a `.env.local` file in the root of the project:

```bash
GEMINI_API_KEY=your_api_key_here
```

You can generate a free API key at **[Google AI Studio](https://aistudio.google.com/)**.

---

## ⚠️ Security Notes

- 🔒 Keep your API key private — never commit it to version control.
- 🛡️ Always call the Gemini API from **backend / server routes**, not directly from the client.
- 🚫 Make sure `.env.local` is listed in `.gitignore` and never exposed publicly.
